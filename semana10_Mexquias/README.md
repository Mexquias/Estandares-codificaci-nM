## Descripción
Calculadora modular que organiza código JavaScript en múltiples archivos usando `export` e `import`.

## Estructura del Proyecto
```
semana10_tu_nombre/
├── css/
│   └── estilos.css
├── js/
│   ├── calculos.js
│   ├── validaciones.js
│   └── app.js
├── index.html
└── README.md
```

## Recomendaciones
1. Usar **Live Server** para ejecutar el proyecto, ya que los módulos JS no funcionan con doble clic.
2. Verificar la consola del navegador (F12) para confirmar que la aplicación se cargó correctamente.
3. Asegurarse de que todos los archivos JS usen `export` e `import` correctamente.
4. Subir el proyecto a GitHub para su entrega.

## Cómo Ejecutar
1. Abrir VS Code
2. Hacer clic derecho en `index.html`
3. Seleccionar **"Open with Live Server"**
4. El navegador abrirá `http://localhost:5500`
5. Presionar F12 → pestaña Consola
