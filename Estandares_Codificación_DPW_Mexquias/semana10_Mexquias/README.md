# Calculadora Modular - Semana 10

Aplicación web modular usando **ES6 Modules** (`import`/`export`).

## Estructura

```
semana10_Mexquias/
├── index.html
├── css/
│   └── estilos.css
├── js/
│   └── app.js          # Punto de entrada
└── modules/
    ├── calculos.js      # Operaciones matemáticas
    └── validaciones.js  # Validación de datos
```

## Temas cubiertos

- Separación de responsabilidades (modularidad)
- Import y export de módulos ES6
- Validación de entradas del usuario
- Manejo de errores con try/catch
